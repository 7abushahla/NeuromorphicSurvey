6 The Two Branches

Sections 2 through 4 fixed what a spiking model computes and what a code represents once weights and thresholds are already given. Obtaining those weights and thresholds is a separate problem. A network can be optimized directly in its spiking form, or a conventional artificial neural network (ANN) can be trained first and its parameters re-expressed as spiking dynamics afterward. This section states why the first option is harder than ordinary backpropagation, introduces the resulting fork into direct training, conversion, and hybrid methods, and names the point at which every route must again agree. Section 7 bounds the direct-training branch to what later sections need. Section 8 derives and extends conversion, the survey's principal branch, in full.

6.1 The Spike Learning Problem

An ANN unit's output \(a^l\), fixed in Section 2.2, is a differentiable function of its input by construction. A static nonlinearity such as a rectifier has a well-defined derivative almost everywhere, and the chain rule propagates a loss gradient back through every layer without further assumption. A spiking unit instead emits \(z_i^l[t]=\mathcal{H}\!\left(\tilde{u}_i^l[t]-\theta_i^l[t]\right)\), the threshold stage fixed in Section 3.2, where \(\mathcal{H}\) is a Heaviside step function. Its derivative with respect to the pre-reset candidate is zero everywhere except at the crossing point, where it is undefined, \[ \frac{\partial z_i^l[t]}{\partial \tilde{u}_i^l[t]} = \mathcal{H}'\!\left(\tilde{u}_i^l[t]-\theta_i^l[t]\right) = 0 \ \text{almost everywhere.} \] The semantic reason is the one Section 2.2 already gave for why a single event carries almost no information on its own. A spike is a binary decision, not a smoothly varying quantity, so the local sensitivity ordinary backpropagation needs at every stage does not exist for it in the mathematical sense used above. The consequence is not that a gradient is merely small, as happens for a saturated sigmoid. Automatic differentiation applied literally to \(\mathcal{H}\) returns zero at every non-crossing step, which stops a learning signal from reaching an earlier layer or an earlier step through this path entirely.

The severity of this obstruction is not the same for every code fixed in Section 4.3. A code that spreads a represented value across many events over a window, such as rate coding, gives a learning rule many chances across the window for a small parameter change to move some event closer to or further from its threshold. A code that concentrates a value into very few events, most sharply time-to-first-spike and rank order coding, correspondingly concentrates whatever local gradient signal survives into those same few events, part of why time-to-first-spike coding trains comparatively slowly despite its fast inference convergence, a dependency Section 4.4 already flagged from the coding side. The two branches below are best read as two different responses to the one obstruction stated above, not as competing claims about which produces the more accurate network.

6.2 Direct Training, Conversion, and Hybrid Methods

Direct training keeps the network in spiking form throughout optimization and works around the obstruction in Section 6.1 rather than avoiding it. One family changes only what happens during the backward pass, replacing \(\mathcal{H}'\) with a smooth surrogate function so that a gradient exists to propagate while the forward pass still emits the exact binary \(z_i^l[t]\). A second family drops the requirement for a loss gradient propagated backward through the whole network and instead updates each synapse from signals already available locally to it. Section 7 takes up both to the depth this survey needs and refers outward for the remainder.

This fork is the lineage of Section 2.1 seen from the learning side, direct training descending from the dynamics branch and conversion descending from the ANN branch.

ANN-to-SNN conversion avoids the obstruction rather than working around it. A conventional ANN is trained by ordinary backpropagation, entirely in the value-based representation of Section 2.2, and only afterward is each unit's activation re-expressed as an integrate-and-fire neuron's spike count or timing under a stated correspondence. No spiking unit exists during training, so the non-differentiable threshold of Section 6.1 is never encountered by the optimizer. Section 8 derives the correspondence this depends on and one complete conversion pipeline, then locates and addresses the error that correspondence accumulates once the simulation horizon is short.

Hybrid methods sit between the two and close a gap that neither route resolves alone. One pattern trains an ANN component and a spiking component separately, each in its own native representation, and joins them at inference through a toolchain built for that purpose. NengoLoihi has been used in exactly this way to deploy a hybrid ANN-plus-SNN model to physical Loihi 1. A second pattern trains a network directly by gradient descent and then applies a hand-designed correction before deployment rather than during training. The mapless-navigation policy of Tang et al. is trained end to end by gradient descent in simulation and is then passed through a Loihi-specific eight-bit integer weight-rescaling step, closing the gap between the training-time numeric format and the chip's native one before the corrected weights are measured on physical Loihi. A hybrid method is therefore not a third optimization principle alongside the two above. It is a stated sequence of steps drawn from them, and what each step preserves or changes has to be stated explicitly rather than left to the label alone. Conversion-specific calibration and fine-tuning, which correct a converted network's spike statistics after the fact, are a further instance of this same pattern and are addressed at their intervention point in Section 8 rather than here.

6.3 Where the Branches Converge

Whichever route produces the weights, the result is still a spiking network of the form fixed in Section 3, carrying a code of the form fixed in Section 4. It must be representable in software, mappable onto a target's neuron cores, and executable within a stated timing model before a deployment claim about it means anything. A network obtained by direct training and a network obtained by conversion do not automatically arrive at this point the same way. Direct training frequently fixes the neuron model, code, and precision to a specific target from the outset, since the gradient or the local rule is computed on the same dynamics the target will run. Conversion fixes these choices afterward, as a separate mapping step from an ANN that was never told during its own training what hardware would eventually execute it. Both are statements about how a given network was obtained, not about which targets it can eventually reach.

What the two branches share is the requirement itself, not a common set of values for it. Section 9 makes that requirement explicit as a single contract that a directly trained network and a converted network are both asked to satisfy before either is compared on a target. No field of that contract is needed here. What matters at this point is only that direct training, taken up next, and conversion, taken up beginning in Section 8, are read against the same eventual requirement rather than as two unrelated literatures.
