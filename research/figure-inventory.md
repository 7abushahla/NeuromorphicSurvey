## Integration defects

1. `tools/build-site.py` still uses an eight-fragment hard-coded build order. It inserts the interactive map after the old Section 7 rather than consuming `data/site-manifest.json` and placing the map after Section 13.

2. `tools/install-figures.py` still iterates over Figures 2 through 6 and installs every static figure into `site/sec-02.html`. It does not use `data/figure-manifest.json`. The advertised `--check` mode is not implemented, so supplying that argument still performs the installation procedure.

3. `tools/check-figures.py` still validates only numbered Figures 2 through 6. It does not inspect planned semantic IDs, manifest destinations, accessible labels, numerical-axis units, or the six new static figures.

4. The fragment layout does not yet match the approved site manifest. `site/sec-02.html` contains all five legacy static figures even though the manifest assigns them across Sections 2 through 4. Section fragments 4, 5, and 9 through 18 are also absent, so the manifest-defined destinations cannot yet be assembled.

Their current viewBoxes are `1130 x 690`, `1526 x 1120`, `1180 x 800`, `1600 x 1048`, and `1200 x 830` for Figures 2 through 6, respectively. This verifies markup structure and identifier isolation only. It does not validate the scientific comparisons identified above.
